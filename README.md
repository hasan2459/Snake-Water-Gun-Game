# 🐍 Snake Water Gun Game

A simple command-line **Snake Water Gun game** built using Python.

In this game, the player competes against the computer. The computer randomly chooses Snake, Water, or Gun, and the winner is decided according to the game rules.

## 🎮 Game Rules

* 🐍 Snake beats 💧 Water
* 💧 Water beats 🔫 Gun
* 🔫 Gun beats 🐍 Snake
* 🤝 Same choice = Draw

## ✨ Features

* 👤 Player vs Computer
* 🎲 Computer randomly selects Snake, Water, or Gun
* 🏆 Player score tracking
* 🤖 Computer score tracking
* 🔄 Multiple rounds
* ⚠️ Invalid input handling
* 🚪 Option to quit the game
* 📊 Final score displayed when the game ends

## 🛠️ Technologies Used

* **Python 3**
* **random module**

## ▶️ How to Run

### 1. Install Python

Make sure Python 3 is installed on your computer.

You can check your Python installation by running:

```bash
python --version
```

### 2. Clone or Download the Project

Download this project and open the project folder in **VS Code** or any other code editor.

### 3. Run the Game

Open the terminal inside the project folder and run:

```bash
python Snake_water_gun.py
```

## 🎯 How to Play

When the game starts, enter one of the following options:

```text
snake
water
gun
quit
```

The computer will randomly select one option, and the winner will be displayed.

The score is updated after every round.

To stop playing, type:

```text
quit
```
